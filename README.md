# Machine Learning and Deep Learning using PyTorch

This repository contains implementations of core **Machine Learning (ML)** and **Deep Learning (DL)** algorithms using **PyTorch**.  
The focus of this project is to understand algorithms from first principles by implementing them using PyTorch tensors, autograd, and neural network modules.

---

## Features

- Pure PyTorch-based implementations
- Classical ML algorithms built using tensors and gradients
- Deep Learning models using `torch.nn.Module`
- Custom training and evaluation loops
- Binary classification and regression examples
- Model saving and loading
- Reproducible experiments

---

## Algorithms Implemented

### Machine Learning
- Linear Regression
- Logistic Regression
- Support Vector Machine (SVM)
- Perceptron
- Gradient Descent
- L1 and L2 Regularization

### Deep Learning
- Artificial Neural Network (ANN)
- Artificial Neural Network (ANN)(Multiclass Classification)
- Multi-Layer Perceptron (MLP)
- Binary Classification using `BCEWithLogitsLoss`
- Regression using `MSELoss`
